# Карта проекта «Касса Оптики» — что где лежит

Обновлено 25.11.2026. Карта для человека; для машины есть граф кода Graphify (`graphify-out/`), с которого
и начинается любой поиск по коду.

## Как смотреть граф

| Что | Где | Для чего |
|---|---|---|
| Картинка графа | `graphify-out/graph.html`, на сайте https://saif-optics.github.io/Kassa/graphify-out/graph.html | Кружки — функции и файлы, цвет — группа (85 групп с русскими названиями: «Новая версия: Касса», «Старый сайт: Платежи (pay.js)» и т.д.). Наведите на кружок — имя и файл, в поиске сверху можно набрать имя функции. |
| Дерево по папкам | `graphify-out/GRAPH_TREE.html`, на сайте https://saif-optics.github.io/Kassa/graphify-out/GRAPH_TREE.html | Раскрывающееся дерево «папка → файл → функции». Удобно, чтобы понять, где что лежит, без кружков. |
| Обзор текстом | `graphify-out/GRAPH_REPORT.md` | Список групп, самые связанные функции («god nodes»), неожиданные связи. |
| Вопрос графу | в терминале из папки репо: `graphify query "касса расхождение"`, `graphify explain "cashState"`, `graphify path "HomePage" "cashState"`, `graphify affected "setDoc"` | Ответ: файл и строка (`src=… loc=L…`). Так ищет и Claude, и его помощники, вместо того чтобы перечитывать проект. |

Граф пересобирается командой `graphify update .` (без интернета, 10–20 секунд) после любой правки кода; сборка
старого сайта (`dev/build.sh`) делает это сама. Названия групп лежат в `graphify-out/.graphify_labels.json`.

## Две версии сайта

| | Старый (рабочий) сайт | Новая версия |
|---|---|---|
| Адрес | https://saif-optics.github.io/Kassa/ | пока только локально, `web/`, порт 5173 |
| Исходники | `dev/base.html` + патчи `dev/patch_*.py` + модули `dev/*/*.js` → собирается в `index.html` | `web/src/` (React, TypeScript, Tailwind) |
| Сборка | `powershell -File dev\build.ps1 -Test` | `npm run build` в `web/` |
| Данные | одна и та же база Supabase `kassa-optiki`, таблица `docs` | та же |
| Правила дизайна | стиль iOS 26 (стекло) | спека `docs/superpowers/specs/2026-11-24-new-design-home-design.md`: цвета бренда, общие компоненты, движение из `web/src/lib/motion.ts` |

Расчёты новой версии сверены со старым сайтом скриптами `web/scripts/*-parity.ts` (Платежи 36, Продажи 155,
План 162, Отчёт и Сверка 425, Аналитика и Склад 1049 проверок). Если меняете расчёт в одной версии, сверка покажет
расхождение со второй.

| `scripts/` | Сверки со старым сайтом (`*-parity.ts` + `*_old.py` через Playwright), скриншоты `shots.py`, выгрузка себестоимости `cost-export.ts` |

## Старый сайт (`dev/`)

| Файл | Что это |
|---|---|
| `base.html` | Основная страница: Главная, Касса, Продажи, Аналитика, План, Линзы, Склад и все расчёты |
| `patch_*.py` | Патчи, которые при сборке вставляют модули в `base.html`: billz, bz, rs, fm, pay, att, role, tasks, ui, tidy. Патч ищет точные строки — если правите текст, который он ищет, сборка упадёт |
| `graph-src/base.html.js` | Зеркало `base.html` для графа, строки совпадают; не править, пересоздаётся сборкой |
| `splash/saif-splash.js` | Заставка с логотипом |
| `test/` | Автотесты (`t_audit`, `t_native`, `t_role`, `t_stress`) и фейк базы `fakesb_synth.js` для сверок |
