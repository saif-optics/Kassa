### На чём написана новая версия

- **React 19** — сам интерфейс (компоненты, состояние).
- **TypeScript 7** — типизированный JavaScript, ошибки ловятся до запуска (`npx tsc -b`).
- **Vite 8** — сборщик и сервер разработки (порт 5173); итог сборки — папка `web/dist`.
- **Tailwind CSS 4** + **shadcn/ui** (на базе Radix) — стили и базовые элементы: кнопки, поля, переключатели, листы снизу, подсказки.
- **Motion** — анимации: перетекающая пилюля меню, посадка карточек; все тайминги в одном файле `web/src/lib/motion.ts`.
- **Recharts** — графики. **TanStack Query** — загрузка данных и кэш. **supabase-js** — связь с базой.
- **sonner** — всплывающие уведомления, **lucide-react** — значки, **react-hook-form + zod** — формы с проверкой, **xlsx** — выгрузки Excel (грузится лениво).
- Код: 12 616 строк в `web/src`, 14 разделов в `web/src/features/`, 10 общих компонентов, 12 используемых shadcn-компонентов.
- Сборка: `tsc -b` чистая, `vite build` 2,1 с; один файл приложения 1,89 МБ (сжатый 558 КБ) + xlsx 492 КБ отдельно + css 110 КБ.
